# 桌面 0.8.0：高级压缩与编码器实时进度

2026-10-31。原生 C++17 / GTK 3 实现，更新弧光压缩管理器。本次不改内核、设置布局或已验收的 0.7.1 完整 ISO。

## 压缩选项

| 格式 | 可选算法 | 功能 |
|---|---|---|
| 7z | LZMA2、LZMA、PPMd、BZip2、仅存储 | 级别、线程、字典/模型、固实、AES-256、文件名加密 |
| ZIP | Deflate、Deflate64、BZip2、LZMA、PPMd、仅存储 | 级别、线程、适用的字典/字长、AES-256 或 ZipCrypto |
| TAR、TAR.GZ、TAR.XZ、TAR.ZST、TAR.BZ2 | 对应格式的算法 | 级别；XZ / Zstandard 可选择线程上限 |

所有创建格式支持自定义分卷大小、排除规则、修改时间保留和完成前完整性测试。文件可以多选、添加文件夹或移除。普通选项保存在用户私有配置中；密码、确认密码、源路径不写入设置文件、日志或进程参数。

线程是上限。LZMA2 支持单个大文件的并行压缩，ZIP 主要按文件并行；单文件不保证占满所选线程。7z 的 PPMd、仅存储及 GZip 等单线程方式会禁用线程选择。字典与字长控件仅在实际支持时启用，显示内存估算并拒绝明显超过物理内存的组合。估算随输入和引擎实现变化，不是测量结果。

ZIP 写入后端遵循 7-Zip 限制：密码采用可打印 ASCII；AES 密码最多 99 字符。中文密码可使用 7z。创建 RAR 不在此版范围内，已有 RAR 读取支持继续由 libarchive 提供。

分卷为连续字节分卷，如 `example.zip.001`、`.002`，并非 PKZIP 的 `.z01` 多盘格式。保留所有分卷并从 `.001` 打开；本程序也可选择中间任意一卷。标准 7-Zip 验证可打开这种 ZIP / 7z 分卷，Windows 自带 ZIP 工具不支持该分卷方式。内置 1800 MiB 预设，亦可输入 `100MB`（十进制）、`100MiB`、`1G`（二进制）或精确字节数；最小 64 KiB。

## 实时压缩比

0.7.1 的 libarchive 7z 写入器在封装前会缓冲数据，读取临时文件长度无法取得实时压缩比。此版 ZIP / 7z 使用系统认证 APT 包 `7zip >= 25.01` 的原生引擎，通过 `ICompressProgressInfo::SetRatioInfo` 获取编码器真实输入、输出计数，与 [7-Zip 25.01 GUI 回调](https://github.com/ip7z/7zip/blob/5e96a8279489832924056b1fa82f29d5837c9469/CPP/7zip/UI/GUI/UpdateCallbackGUI.cpp)采用同一接口。

压缩比 = 编码器输出 ÷ 编码器已处理输入 × 100%。统计包含编码器已产生、归档层尚未写出的数据；不是最终大小预测，也不是节省百分比。完成时改用完整归档大小 ÷ 原始总大小，包含头部和索引，所以最后的比例可能略微变化。空文件或编码器尚未报告数据时不猜测数值。

进度窗口同时显示编码器压缩后大小、实际已写出大小、卷数、算法、线程上限、两条进度条、原始总大小、速度及预计时间。引擎的工作总量可能包含 ZIP 头部开销，与原始字节总量分别记录。封装、测试和发布完成前不会显示 100%。

## 输入与发布保护

源文件在扫描、打开及压缩后检查身份、大小和修改时间；发生改变拒绝发布。保持禁止创建链接/特殊文件、路径越界预检查、解压目录逐级禁止跟随链接、默认跳过同名文件、完整文件校验后发布的保护。

压缩先写入同目录的私有临时目录。每卷同步后，以不覆盖已有文件的方式发布，第一卷最后发布；取消或冲突会回收本任务已发布的卷。取消解压保留已完成文件，移除未完成文件。暂停和取消在引擎回调边界生效，内部尚未返回的计算可能有短暂延迟。异常掉电不等同于正常取消。
