# 桌面 0.9.0：显示草稿、独显直连与快捷控制

本轮在独立 `dev` 分支修改，基于实体机已安装的 0.8.0。原生程序继续使用 C++17 / GTK 3，保留 Pi 主题、labwc / Wayland、按标签页应用和独立显示回滚进程。内核 ABI 与 NVIDIA 驱动版本不变。

显示页原先把保存回调放在按钮容器中，而显示控件位于其旁边的显示屏分组。旧的追踪逻辑只认保存按钮的父容器，因此所有显示控件均被当作非持久操作参数，无法激活右上角应用。现在保存回调可以声明明确的作用域，显示页覆盖整组显示控件。测试直接创建真实显示页，检查分辨率/缩放控件、按钮敏感性、更改计数、路径及还原。

应用按钮左侧显示全局待应用项目数；悬停可见位置，点击展开列表并跳转到相应分类、标签页和控件。列表不显示设置值或密码。切换页面不会清除草稿，改回原值会移除该项。应用仍只保存当前标签页；成功的保存作用域立即更新基线，后续认证或校验失败时，尚未保存的项目继续保留。

物理模式直接来自当前合成器，不伪造不可用的分辨率。在本机 NVIDIA 直连的 eDP-2 上，EDID 与合成器提供 2560×1600 的 60/165Hz 两个模式；1920×1200 自定义模式的仅测试请求被驱动拒绝。AMD 混合模式下的更多缩放模式不能据此视为 NVIDIA 支持的物理时序。显示页新增随分辨率、旋转和缩放更新的“桌面有效空间”说明，明确区分界面缩放与物理分辨率。实体模式测试和限制单独记录。

已安装的 `arclight-nvidia-userspace` 实际含 `nvidia-settings 615.78.08` 及 GTK3 库，原先漏掉菜单入口。桌面包现在提供带 `TryExec` 的 NVIDIA X Server Settings 菜单项，关于本机也可打开控制面板。没有 GPU 或未安装可选驱动时不显示菜单项；没有安装另一套冲突的 Debian NVIDIA 驱动。NVIDIA 官方说明该工具在 Wayland 下功能有限，显示布局继续交给合成器：[615.78.08 Wayland 限制](https://download.nvidia.com/XFree86/Linux-x86_64/615.78.08/README/wayland-issues.html)。32 位 Wine/Steam 驱动库仍不在现有发行范围内。

新增 `arclight-osd` 原生程序，使用已有 `libgtk-layer-shell0` 的公开 GTK3 ABI。在屏幕下方显示圆角半透明浮层、主题图标、实际百分比和分段条；连续按键刷新同一个浮层，松开后约 1.6 秒消失。浮层请求零键盘交互及空输入区域，不改变窗口焦点。音量使用当前默认输出，麦克风静音使用默认输入；背光通过 logind 调整当前会话的背光接口。音量快捷键最高 100%，背光最低 1%；设备失败显示简短提示，不显示猜测的成功值。

会话助手仅替换 Pi 默认 `wfpanelctl volumepulse` 的三个音量绑定，并补充缺失的亮度和麦克风绑定。已有自定义快捷键、多动作绑定和其他 labwc 配置保留，写入前备份；迁移重复执行不再改变配置。安装后可运行 `arclight-session --refresh-desktop` 重新读取桌面默认项及快捷键，无须重启或注销。

独立 GUI、音频和实体检查的最终范围、包哈希及完整 ISO 结果以本轮验证文件和后续镜像说明为准，不继承旧版通过状态。

最终 DEB SHA256 为 `34b3b10d68e6f7c660c156ff790e5ae7fcf53f7531a2252e1ddfb11304837e4d`。78 项原生、119 项压缩器、17 项恢复策略、16 项按页应用、180 个布局视图和 8 项 OSD 检查通过。真实实体 GUI 另验证了点击应用、125% 临时生效、确认对话框、20 秒超时恢复及未保存草稿保留；最终包的背光动作实际通过 40→45→40。9 个安装 ELF 与最终包一致。回退包及安装状态保存在 `/var/backups/arclight-desktop-0.9.0-20261031-r2/`，旧设置窗口关闭后重新打开使用新版。
