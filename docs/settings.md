`yydaniel-desktop 0.3.2` 以 Astgenne Settings（星源系统设置）提供，入口为 `astgenne-settings`，保留旧入口兼容。程序使用 C++17、GTK 3、GIO/DBus。主程序、会话管理与显示回滚进程、系统权限辅助程序均由 g++ 编译为原生 ELF。安装包不包含 Python 代码，也不依赖 Python 解释器。工程下载、清单与 ISO 构建脚本仍可使用 Python 或 Shell。

主窗口采用分类侧栏、搜索和标签页；颜色、控件、图标与字体跟随 Raspberry Pi 桌面主题。现有树莓派设置直接通过其 C 插件 ABI 嵌入，专业管理工具按需独立启动。

原生 Pi 模块包括 rc-gui、pipanel、rasputin、pished、raindrop、wf-panel-pi 与 rpinters。菜单编辑器通过原生 `rpcc main_menu` 启动，避免菜单缓存初始化影响主窗口。IP/VPN、软件包、输入引擎、磁盘等复杂编辑继续使用系统对应工具。首次需要但未安装的组件可在软件包页安装。

高级页涵盖 raspi-config 的 SPI、I²C、单总线、串口控制台/UART、PCIe、LED、网络安装、关机供电、A/B 固件、Wi-Fi 省电、本地地址回退、USB 供电、留白、模拟视频、Pi 4 视频模式、扩展根分区、启动顺序、固件通道与测试版通道。板载接口和固件项目在非树莓派上禁用，权限程序会再次核验硬件。面向终端的交互式工具仍可运行 `sudo raspi-config`；依赖特定板卡/硬件的选项不在 x86 上伪装为可用。

显示更改先调用输出协议测试，临时生效后要求 20 秒内确认；独立的原生进程负责超时回滚，即使 GUI 崩溃也继续运行。确认后保存 kanshi 配置块，保留其他配置及备份。系统设置以有限动作和 JSON 参数通过 polkit 认证，不接收任意 shell 命令；密码通过 stdin 或 DBus 传输，不放入命令行。共享配置和 TLS 私钥限制为当前用户可读。

构建与测试：

```sh
sudo apt install build-essential debhelper libgtk-3-dev libxml2-dev libarchive-dev libwayland-dev libx11-dev wayland-protocols libcrypt-dev nlohmann-json3-dev pkg-config
make -C desktop -j2
make -C desktop check
bash scripts/build-desktop.sh
# 安装包后，在当前用户的 Wayland 会话中运行
bash scripts/test-settings-smoke.sh
bash scripts/test-multihead.sh
```

22 项原生后端校验及隔离双输出测试已通过；19 类 GUI 页及 44 个页面/标签视图已逐项检查。虚拟机没有真实 NVIDIA GPU、蓝牙、Wi-Fi 或背光硬件，不能用无设备页面替代相应实体机验证。没有自动更改实际网卡、防火墙、账户、电源策略或共享状态来充当测试。

0.3.1 为所有页面与分组设置至少 12 个逻辑像素的内边距，包含嵌入的 Pi 设置页。按钮、开关及输入控件居中对齐，使用 Pi 主题的自然高度，不随多行提示拉伸。GUI 检查会逐一切换分类和标签页，记录实际分配高度与主题自然高度，并保存原生渲染截图。
