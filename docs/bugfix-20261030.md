# 2026-10-30 系统问题修订

用户已报告完成实体机安装。本轮针对 `buglist.txt`，不把安装反馈当作硬件适配验收。旧发行 ISO、冻结源码和原有验收记录保留；本轮桌面组件版本为 0.4.0。

| 项目 | 修改 | 实体验收范围 |
|---|---|---|
| 1. APT 拉入 7.2 | 限制两个 Debian 通用内核元包从 backports 自动迁移；保留 stable/security 的回退更新、Astesia 和版本化内核。`linux-libc-dev` 是用户态开发头文件，继续正常更新 | 用户日志仅显示安装了 7.2 头文件，不证明已启动 7.2；不自动删除任何现有内核或头文件 |
| 2. NTFS 挂载需 root 密码 | 仅允许本机活动 sudo 组用户通过 UDisks 挂载内部 NTFS；不放开格式化、BitLocker 解锁、fstab 或其他会话权限 | Windows 快速启动/休眠及脏文件系统的拒绝仍保留，不强制写入或删除休眠文件 |
| 3. 文件管理 | 在现有 `pcmanfm-pi`/libfm 上增加原生文件操作入口：目录终端、归档、解压和设备安全断电；保持 Pi 桌面 | 安全移除先检查整台设备、卸载所有分区，失败停止；只有 UDisks 明确支持断电且无系统分区的设备才提供 |
| 4. 显示设置过大 | 实际 150% 截图发现侧栏“显示屏”图标尺寸异常；固定侧栏图标为 16 个逻辑像素并居中，在逐页测试中检查图标分配尺寸；主窗口允许更小的逻辑尺寸 | 保留原生排列页、12px 留白、自然控件高度和独立 20 秒回退 |
| 5. 截图工具 | C++/GTK 原生区域/全屏截图、矩形、椭圆、箭头、画笔、文字、马赛克、撤销、PNG 保存和剪贴板；grim/slurp 负责 Wayland 捕获 | 默认区域选择；菜单提供全屏。登录时添加未被占用的 Print 和 Ctrl+Alt+A，保留已有绑定 |
| 6. 触控板 | 自然滚动、轻触/拖动/锁定、键入禁用、左手模式、滚动/点击方法、加速和速度；只修改 labwc 触控板块并备份配置 | 无设备的虚拟测试不算实际触控板通过；X11 使用原生鼠标设置 |
| 7. 时间与 RTC | 显示真实 RTC 模式，提供 Windows 本地 RTC 开关，通过 timedated 的认证接口保存；切换时保留当前系统时间 | 本地 RTC 的夏令时/跨时区限制会在界面说明；时区、NTP 和手动时间保留 |
| 8. ISO 升级 | 单独升级介质、首轮引导脚本及后续图形入口，校验整个 ISO 与逐包哈希，模拟实际依赖，不联网、不删除、不降级 | 不重分区；不承诺整机事务回滚。详见 [离线升级](offline-upgrade.md) |

归档操作使用 Debian 的 Archive Manager（file-roller），提供格式检测、目标选择、密码、覆盖冲突、进度和取消；项目没有重新实现解压算法。文件名按参数数组传递，不能作为 shell 命令执行。

触控板参数依据 [labwc 配置文档](https://labwc.github.io/labwc-config.5.html)，存储权限依据 [UDisks 授权接口](https://storaged.org/doc/udisks2-api/latest/udisks-polkit-actions.html)。Pi 原生桌面仍使用其已有的模块与主题。

本轮构建、自动测试、实际查看的截图和升级测试结果以随升级包提供的验证记录为准。NVIDIA、真实 NTFS 盘、触控板、USB 断电、双系统 RTC 与实体缩放操作仍须在用户机器分别复测，不记为已验收。
