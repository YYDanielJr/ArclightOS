# ArclightOS 0.9.0 完整镜像

本轮工作区为 `.local/iso-0.9.0/`，目标文件为 `arclightos-trixie-amd64-20261031-0.9.0.iso`。0.8.0 已验收镜像、源码及发布清单保留，不覆盖。

镜像输入从 0.8.0 的已认证集合独立派生，共 1883 包，仅更新 `arclight-desktop` / `yydaniel-desktop` 两包至 0.9.0。其余 1881 包的版本、哈希和真实来源保持原样，包括 AscalonKernel `7.3.0-ascalonkernel`、Debian 回退内核、GRUB、安装器以及可选 NVIDIA 615.78.08。没有恢复 Debian 全量源码重编译，也没有下载替代包补洞。

桌面提供显示页更改追踪、待应用计数及位置跳转、实际有效桌面空间、原生 Wayland 快捷控制 OSD，以及已有 NVIDIA Settings 的菜单入口。详细功能见 [桌面 0.9.0](desktop-0.9.0.md)，RTX 5060 Laptop 独显直连实测与未测项见 [实体报告](hardware-validation/2026-10-31-tx-air-fa401km-nvidia-direct/validation.md)。虚拟机镜像测试不能替代实体 GPU、外接屏、电源或 Secure Boot 验收。

最终桌面包 SHA256：`34b3b10d68e6f7c660c156ff790e5ae7fcf53f7531a2252e1ddfb11304837e4d`。78 项原生、119 项压缩器、17 项恢复策略、16 项按页应用、180 个页面布局和 8 项 OSD 检查通过，最终安装 9 个 ELF 与包内一致。

冻结工程源码为 `arclightos-source-20261031-0.9.0-input.tar.xz`，后续维护和最终验收工具另存 `arclightos-source-20261031-0.9.0-release.tar.xz`。主装配脚本、显示/OSD 源码和构建配方均与冻结输入匹配。准备输入与发布打包工具在冻结后补充了跨工作区路径适配及证据归档，这些变更保留在最终发布源码和 `factory-recipe.json`，不覆盖冻结归档。

离线构建使用实体 Linux 宿主的 KVM 硬件加速、8 GiB 内存、3 个 vCPU、全新 80 GiB 虚拟构建盘、无网卡和只读输入；不连接宿主实体磁盘，不复制宿主根文件系统。初次启动脚本因同一 project 9p 标签已挂载而在真正装配前停止，记录保留；核对构建盘仍为空后使用只读 bind mount 继续，没有放宽数据盘身份/空盘检查。新仓库位于历史构建树之外，工具与官方基础 ISO 改为可在来宾内独立解析的副本，版本/哈希不变。

本镜像装配完成，主内核 BIOS / UEFI Live 均已实际启动并采集证明。用户随后追加界面修改，目标推进到 0.9.1；0.9.0 的安装验收在写入测试盘前结束，两台来宾正常关机。没有完成本版六项矩阵，不将其作为最终发行；0.9.1 使用独立工作区和新证明重新验收。
