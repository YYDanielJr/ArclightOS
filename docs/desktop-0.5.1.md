# 桌面修订 0.5.1（含 0.5.0 功能）（2026-10-30）

本次针对实体安装上的输入法、设置应用、截图及压缩管理器。只更新
`yydaniel-desktop`；不修改内核、NVIDIA、已验收安装 ISO 或冻结发布清单。

## 输入法

原 `managed_environment()` 将同一份带 shell 单引号的内容写入 systemd
`environment.d` 和 `labwc/environment`。labwc 保留这些引号，实际会话中的
`GTK_IM_MODULE`、`QT_IM_MODULE` 与 `XMODIFIERS` 都变成了包含单引号的值。
修订分别序列化两种文件格式，labwc 使用 `XMODIFIERS=@im=fcitx` 等字面值。

0.5.1 同时修复现场检查发现的修复助手等待守护进程日志管道的问题，并排除升级 ISO 参数等非持久操作输入的待应用状态。

会话助手启动时只迁移本程序管理的输入法块，保留其他设置并生成备份。
`yydaniel-session --repair-input-method` 可主动修复当前用户的文件，更新
D-Bus/systemd 用户环境、重新读取 labwc 配置并重启 Fcitx。已运行的应用和面板
仍保留启动时的环境；保存工作后注销并重新登录，可以统一刷新全部进程。
不会自动退出当前桌面或聊天应用。

依据：[labwc 配置格式](https://labwc.github.io/labwc-config.5.html)、
[Fcitx Wayland/XWayland 环境说明](https://fcitx-im.org/wiki/Using_Fcitx_5_on_Wayland)。

## 按页面应用设置

右上角“应用”提交当前页面的更改，标签页作为独立页面。原分组内的保存按钮
改为内部保存回调；只有包含更改的分组执行回调。跨页面的草稿分别保留，
改回原值会清除待应用状态。异步保存顺序执行，失败或拒绝显示设置时保留草稿，
关闭窗口时可以继续编辑或放弃更改。

Pi 原生模块的控件变更信号处理器在编辑阶段阻塞，在当前页面应用时重新发出。
其 API 原本定义为即时保存，并没有事务接口，因此各模块依然调用原有后端。
一页内多项操作不保证全部成功或全部回滚；前一项成功、后一项失败时不会声称
后端已整体撤销。连接/扫描、安装软件包、账户操作、打开独立工具等操作保留
独立按钮。显示设置保留 20 秒确认及独立回滚进程。

## 星源截图

默认选区通过 slurp 高亮鼠标所在的预定义窗口，单击选择窗口，拖动选择任意区域，
Esc 取消。XWayland 窗口可查询 X11 边界；原生 Wayland 窗口通过 labwc 提供的
`ext-foreign-toplevel-list` / `ext-image-copy-capture` 截图，与逻辑像素桌面图像
匹配定位。匹配需要足够的可见内容；被严重遮挡、正在变化或无法唯一匹配的窗口
仍可拖选，不猜测窗口位置。不需要替换或重启合成器。

编辑器提供箭头、矩形、椭圆、直线、实心矩形、荧光笔、画笔、马赛克及多行文字，
可选择颜色、线宽及独立字号。支持撤销/重做、PNG 保存、复制并完成；快捷键包括
Ctrl+Z、Ctrl+Shift+Z / Ctrl+Y、Ctrl+S、Ctrl+C。临时截图使用私有文件，取消后清理。

## 星源压缩文件管理器

新增 C++17 / GTK 3 / libarchive 原生程序 `astgenne-archive`，继承 Pi GTK 主题。
支持压缩包文件列表及排序、新建 ZIP / 7z / tar.gz、压缩级别、ZIP AES-256 密码、
完整性检查、解压位置、同名文件跳过或显式替换、进度及取消。可读取 libarchive
支持的 RAR 等格式，以及单个 gzip/xz/bzip2 等压缩流。

文件管理器右键压缩/解压改用新程序；登录时只替换 File Roller 或空缺的默认关联，
保留用户选择的其他程序。默认将解压结果放入独立子目录，同名文件跳过。
整个清单先检查再写入，拒绝绝对路径、`..`、链接及特殊文件；目标目录逐段以
`O_NOFOLLOW` 打开。单个文件通过临时文件完成后发布，取消保留已完整解出的文件。
创建压缩包也在完成后发布，失败不覆盖原文件。

当前不创建 RAR，不提供修改已有压缩包、分卷或 7z 密码创建；含链接的源码包会
显示明确拒绝信息，需使用支持相应语义的工具。加密格式是否可读取决于 libarchive。
