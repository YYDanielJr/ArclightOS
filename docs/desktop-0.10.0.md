# 桌面 0.10.0：压缩包更新

本版保留 C++17 / GTK 3 原生程序。设置中的升级入口改为 TAR.XZ / TAR.ZST；原 ISO 协议保留迁移兼容。整包 SHA256、逐包哈希、目标架构、安装条件、空间、依赖和 dpkg 状态均检查后才能安装。

更新包只分发项目/本地构建包；NVIDIA 闭源载荷明确标识为厂商二进制。Debian/Pi 原生包通过正常认证 APT 更新；离线依赖缺失时停止。安装不删除包、不降级、不自动清理，不给未安装 NVIDIA 的机器强装驱动。

新内核保留旧内核为永久默认，通过 initramfs 与五模块检查后安排一次 GRUB 试启动，不主动重启。该流程不等于系统快照，dpkg 中途失败仍须按日志恢复。

最终干净源码构建通过 103 项原生检查、119 项高级压缩检查和 17 项会话恢复检查。19 分类、49 视图在三种缩放及 640px 窄窗口共 196 个视图检查通过；最终交付构建另行通过升级页四个窗口/缩放用例。第一轮隔离音频服务缺失的测试没有计为通过，指定实际只读音频信息端点后重跑通过。布局矩阵和最终构建的四个布局源文件哈希一致。

解包检查覆盖路径越界、绝对路径、链接、重复文件、展开大小；生成器检查来源、DEB/buildinfo 哈希、对应源码覆盖及禁止覆写。实际包升级与错误哈希/过期计划拒绝结果另存安装验收报告。使用方法见 [压缩包升级](offline-upgrade.md)。
