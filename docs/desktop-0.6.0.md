- 项目自己的相邻操作按钮改为紧密横排，窗口变窄时自动换行；覆盖蓝牙扫描、设备

- 缩小重复的标题栏、标签页外层留白及行距；分组内边距继续至少为 12px，按钮和

- 只读内容采用“项目—值”两列布局。“关于本机”合并桌面/会话、处理器/线程数，

  缺少检测工具时如实显示“未检测”。

## 压缩任务窗口

参考 [7-Zip 官方进度窗口源码](https://github.com/ip7z/7zip/blob/main/CPP/7zip/UI/FileManager/ProgressDialog2.cpp)
的信息组织，以及 [WinRAR 操作进度说明](https://winrar.es/soporte/manual/HELPExecArcCmd)
的当前文件/总体进度结构，使用 C++17 / GTK 3 实现，颜色和控件沿用 Pi 主题。

独立窗口显示当前文件与总体进度两条进度条，以及原始总大小、已处理原始数据、
压缩后大小、压缩比、文件数量、处理速度、已用时间和预计剩余时间。可暂停/继续、
取消或转入后台；主窗口可重新打开进度窗口，任务完成后保留 100% 和最终统计。
解压和完整性检查也使用相同界面；压缩后大小/压缩比仅在创建压缩包时显示。

统计先扫描输入文件，再累计实际读取的字节；压缩后大小来自临时输出文件的实际
长度。压缩比定义为“压缩后大小 ÷ 已处理原始数据”，包含容器头部，不能压缩的
小文件可能超过 100%。进度在封装、同步和发布完成前最多为 99%，不因原始数据
已经读完就宣布完成。输入文件大小改变时会拒绝继续使用过期的总量。

7z 写入器会缓存容器数据，尚未写出时显示“等待封装写入”，压缩比显示“—”；
完成后显示真实结果。未知总量保持未定状态，不生成虚假的百分比。速度按已处理
原始数据和有效运行时间计算，暂停时间不计入；剩余时间是动态估算。暂停/取消
在后端进度回调处生效，不能中断压缩库内部尚未返回的一次计算。

保留路径预检查、禁止跟随目标链接、默认跳过同名文件及临时文件发布方式；取消
不留下半成品压缩包。也修正了单独选择一个普通文件时，归档文件名可能带多余
目录后缀的问题，增加完整往返检查。
